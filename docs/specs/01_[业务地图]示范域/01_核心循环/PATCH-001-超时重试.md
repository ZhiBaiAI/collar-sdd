| **原状态** | 单次调用超时即失败，不重试 |
| **新状态** | 最多重试 ⟨2⟩ 次，退避 ⟨200ms → 800ms⟩，仅对幂等接口生效 |

## ② 动机

线上偶发网络抖动导致核心循环整体失败，用户侧表现为「莫名其妙没结果」。
属于编码过程中发现的改进，而非原 Spec 设计遗漏。

## ③ 改了什么

- **行为**：⟨接口⟩ 超时后按退避策略重试，超过 ⟨2⟩ 次才失败
- **限制**：仅幂等接口重试（避免重复提交）
- **配置**：新增 `⟨RETRY_MAX⟩` / `⟨RETRY_BACKOFF_MS⟩`，默认值见上

## ④ 兼容性

无破坏性。非幂等接口行为不变。

## ⑤ 主文档反向指针（主文档 → Patch）

已在 [spec.md](./spec.md) 「3.1 超时与重试」处加入取代标记与生效日期。

## ⑥ 验收标准

- [ ] 给定首次超时，当调用幂等接口，则重试且第二次成功时整体返回成功
- [ ] 给定连续 ⟨3⟩ 次超时，当调用幂等接口，则最终失败且耗时 < ⟨3s⟩
- [ ] 给定非幂等接口，当首次超时，则**不重试**直接失败
