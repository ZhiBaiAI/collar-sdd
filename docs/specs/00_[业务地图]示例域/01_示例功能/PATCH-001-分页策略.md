| **原状态** | 偏移量分页（`page` + `pageSize`，默认 20） |
| **新状态** | 游标分页（`cursor` + `pageSize`，上限 100） |
| 是否破坏性 | **是** —— `page` 参数废弃，需调用方迁移 |

## ② 动机

数据量超过 ⟨10 万⟩ 后，深翻页的偏移量分页产生严重慢查询。
编码过程中实测确认游标分页可解决，属于「编码时发现了更好的方案」。

## ③ 改了什么

- **接口**：`page` 移除，新增 `cursor`（不透明字符串，服务端签发）
- **数据**：无迁移
- **配置**：新增 `DEMO_MAX_PAGE_SIZE`，默认 100

## ④ 兼容性

灰度期内 `page` 与 `cursor` 并存：传 `page` 走旧逻辑并打告警日志，
连续 ⟨14⟩ 天无 `page` 调用后移除旧分支。
