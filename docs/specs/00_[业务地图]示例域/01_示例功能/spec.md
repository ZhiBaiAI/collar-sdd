## 1. 背景与目标

- **要解决什么问题**：新同学接手项目时，没有一份能照着抄的 Spec 样例。
- **不解决什么**：不承载真实业务逻辑。
- **目标指标**：新人读完本文件 + 相邻 PATCH 后，能独立写出一份合格 Spec。

## 2. 用户故事

## 3. 方案设计

### 3.1 整体流程

请求 → 参数校验 → 业务处理 → 结果返回。无外部依赖。

| `/api/demo` | GET | `keyword?: string` | `{ items: Item[]; total: number }` | 是 | 只读 |
